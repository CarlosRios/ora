# Ora

A small, static Catholic prayer companion built with React and Vite.

## Included prayers

- The Holy Rosary with Joyful, Luminous, Sorrowful, and Glorious Mysteries
- The Jesus Prayer
- The Apostles' Creed
- The Act of Contrition
- The Morning Offering
- Grace Before Meals
- Grace After Meals
- St. Michael the Archangel Prayer

The Rosary page presents all four sets of mysteries and a concise prayer order. Theme preference is stored locally. There are no accounts, analytics, or external services.

Scripture passages are from the public-domain [Douay–Rheims American Edition (1899)](https://github.com/midvash/bible-data/tree/main/versions/en/dra), a Catholic translation of the Latin Vulgate.

## Run locally

```bash
npm install
npm run dev
```

## Build the static site

```bash
npm run build
```

The production site is written to `dist/` and can be hosted on any static hosting service.
